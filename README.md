# Joust

A faithful clone of the classic arcade game *Joust*, built with Python and
pygame-ce. It features HD pixel art, one- and two-player play, keyboard and
gamepad controls, and code-generated sprites and sound effects. All game
assets are generated by the scripts in `tools/`; no hand-authored binary
assets are required.

## Python game and Unity rebuild

The default `master` branch contains the Python game documented below. A separate
[`feat/unity-m0-spike` branch](https://github.com/DeadeyeDuncan/joust-clone/tree/feat/unity-m0-spike)
contains the Unity 6 rebuild alongside it. See the
[Unity progress website](https://deadeyeduncan.github.io/joust-clone/) for findings
and screenshots; this is a progress report, not a browser-playable game.

The Unity branch includes the core loop and M2 work on eggs, enemy tiers, lava,
respawning and waves. Full arcade parity and a shipping build are not yet claimed.
The recorded build uses Mono; IL2CPP support and the remaining user smoke checks
are still open. Open `unity/JoustUnity` with Unity **6000.5.10f1** on that branch.
Its test wrappers are in `unity/tools/`; their editor paths must match your machine.

To regenerate its website, run `python unity/tools/build-progress-site.py` from
the Unity branch. Existing tracked screenshots are retained when local capture
artifacts are absent. Publication serves the contents of `site/` from `gh-pages`.

## Python requirements

- Python 3.13
- [pygame-ce](https://pyga.me/)
- [Pillow](https://python-pillow.org/)
- [NumPy](https://numpy.org/)
- [pytest](https://pytest.org/) (for tests)

## Setup

Create and activate a virtual environment, then install the dependencies:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install pygame-ce pillow numpy pytest
```

## Run

```powershell
python -m joust
```

From the title screen, press `1` for one player or `2` for two players.

## Controls

| Action | Player 1 | Player 2 |
|---|---|---|
| Move left/right | Left/Right arrows | `A` / `D` |
| Flap | `Space` | Left Shift |
| Gamepad movement | Controller 1 axis 0 or hat 0 | Controller 2 axis 0 or hat 0 |
| Gamepad flap | Controller 1 button 0 | Controller 2 button 0 |

| General action | Control |
|---|---|
| Select one/two players | `1` / `2` |
| Pause/resume | `P` |
| Return to menu | `Esc` |
| Toggle fullscreen | `F11` |

Gamepads are assigned in controller order. On the title screen, button 6 or
7 on controller 1 starts one-player mode; the same buttons on controller 2
start two-player mode.

## Regenerate assets

Generate the sprite sheets and sound effects from source:

```powershell
python tools/gen_sprites.py
python tools/gen_sfx.py
```

The game automatically runs both generators once at startup if required
assets are missing or stale.

## Tests

```powershell
pytest tests
```

## Build a Windows executable

After installing PyInstaller, run:

```powershell
pyinstaller --onefile --add-data "assets;assets" -n joust joust/__main__.py
```

The quotes around `assets;assets` are required in PowerShell.
